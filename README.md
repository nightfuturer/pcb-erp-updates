# 板联 ERP 更新发布

面向线路板采购、销售与仓库协作的内网 ERP。办公室服务器统一保存数据，同事通过浏览器使用。

本仓库用于发布签名更新包，程序源代码包含在更新包中。这里不保存公司业务数据、账号、数据库备份或发布私钥。

## 更新方式

管理员打开「团队与设置 → 系统更新」，配置发布公钥及版本清单地址：

```text
https://github.com/nightfuturer/pcb-erp-updates/releases/latest/download/update.json
```

- `update.json`：签名版本清单。
- `erp-版本.erp-update`：系统在线下载的程序包。
- `erp-版本.erp-bundle`：网络不便时手动上传的离线包。

公钥由发布维护人员提供。只有签名、文件校验和兼容性检查通过的更高版本才能安装。服务运行期间可每天自动检查，安装须管理员确认；更新前自动备份，新版启动失败会回退。

0.2.0 是更新机制的基线版本，已运行 0.2.0 的系统会显示最新，不需要重新安装本版。更新附件不是全新安装包；首次部署需要带启动器的完整项目及 Node.js 24 或更高版本。

当前不支持通过一键更新迁移数据库结构或更换启动器协议，也不支持需要登录的私有 Release 下载。GitHub 无法访问时，原 ERP 仍可正常使用，可以改用同一版本的离线包。
